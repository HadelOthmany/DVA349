# DVA349 – Artificial Intelligence Laboratory Assignments

This repository contains my laboratory assignments for the course **DVA349** at Mälardalen University.

The course focuses on different areas of Artificial Intelligence, including search algorithms, constraint satisfaction, metaheuristics, adversarial search, and artificial neural networks.

## Course Structure

The course consists of five laboratory assignments:

| Assignment | Topic | Language |
|---|---|---|
| LAB1 | Solving Problems by Searching | C |
| LAB2 | Constraint Satisfaction Problems | C |
| LAB3 | Metaheuristics | Python |
| LAB4 | Adversarial Search | Python |
| LAB5 | Artificial Neural Networks | Python |

## Assignments

### LAB1 – Solving Problems by Searching

The first assignment focuses on solving problems using search algorithms.

The implementation is written in **C**.

Topics include concepts such as:

- State-space search
- Search strategies
- Problem representation
- Finding solutions efficiently

---

### LAB2 – Constraint Satisfaction Problems

The second assignment focuses on **Constraint Satisfaction Problems (CSP)**.

The implementation is written in **C**.

The assignment explores how a problem can be represented using:

- Variables
- Domains
- Constraints
- Search techniques for finding valid solutions

---

### LAB3 – Metaheuristics

The third assignment focuses on **metaheuristic optimization methods**.

The implementation is written in **Python**.

The purpose is to investigate optimization techniques that can be used to find good solutions to difficult search problems.

---

### LAB4 – Adversarial Search

The fourth assignment focuses on **adversarial search**.

The implementation is written in **Python**, as required by the course.

The assignment explores decision-making in environments where multiple agents or opponents have competing objectives.

Topics may include:

- Game trees
- Minimax
- Decision making
- Adversarial environments

---

### LAB5 – Artificial Neural Networks

The fifth assignment focuses on **Artificial Neural Networks**.

The implementation is written in **Python**.

The assignment introduces concepts related to machine learning and neural networks, such as:

- Neural network structure
- Training
- Input and output data
- Prediction and evaluation
